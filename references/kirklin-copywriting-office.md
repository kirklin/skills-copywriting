# 办公应用界面文案规范

## 一、范围

适用于办公协作、企业后台和团队工具类产品，覆盖用户看得到的所有文字：按钮、标题、标签、提示、弹窗、报错、空状态、开关说明、引导和通知。示例里的 `{产品名}` 换成产品自己的名字。

## 二、硬性规则

1. 称呼统一用「你」，不用「您」。
2. 提示、说明和报错的句末不用句号。两句以上时，句子之间用「。」，最后一句末尾仍不用句号。问句保留问号。
3. 名称写在中文弯引号“”里：`群主将此群设置为“不可被分享”，请升级至最新版体验完整群主权限功能`、`暂不支持保存到“我的文件夹”，请稍后重试`。产品自己的名字直接写，不加引号：`请将{产品名}客户端升级至最新版本后重试`。
4. 菜单路径写在“”里，层级之间用「 > 」：`可随时在“设置 > 通用 > 自动翻译”中再次开启群名自动翻译`。
5. 数字、英文单词和变量两边留空格：`最多选择 100 条消息`、`SSO 认证失效，请重新认证`、`一次最多转发 {{select_count}} 个会话`、`{{name}} 预约了你的日程`。
6. 括号和冒号用全角。
7. 进行中的状态和输入框的占位文字末尾加三个英文句点：`加载中...`、`保存中...`、`请输入你的状态...`。
8. 权限和安全限制先写原因，再写结果和找谁处理：`由于管理员的权限设置，你无法查看该文件。如有疑问，请联系企业管理员`。
9. 感叹号和「啦」「吧」「哦」只用在新功能介绍、引导和空状态里：`群保密设置功能上新！`、`页面空空如也，分享你的第 1 条动态吧！`。报错、权限和确认弹窗里不用。
10. 按钮 2 到 4 个字，不用标点。
11. 不用「温馨提示」开头。「抱歉」只用在功能升级和页面加载失败：`抱歉，页面加载失败`。

## 三、句式

| 场景 | 写法 | 示例 |
|-|-|-|
| 没做成 | X 失败 | `发送失败`、`上传失败` |
| 没做成，给出下一步 | X 失败，请重试；X 失败，请稍后重试 | `操作失败，请重试`、`保存失败，请重试` |
| 通用报错 | 情况，请稍后重试 | `发生了一些错误，请稍后重试`、`网络异常，请稍后重试` |
| 做不了，说明原因 | 无法 X，原因 | `无法下载，当前文件存在安全风险`、`无法发送，文件夹是空的` |
| 不支持 | 暂不支持 X | `暂不支持打开此类型文件` |
| 进行中 | X 中...、正在 X | `加载中...`、`正在下载` |
| 请用户等待 | ……，请稍候 | `加载中，请稍候` |
| 完成后的轻提示 | X 成功 | `复制成功`、`操作成功` |
| 完成后的状态 | 已 X | `已完成`、`已关注` |
| 空状态 | 暂无 X | `暂无内容`、`暂无数据` |
| 搜索没有结果 | 没有搜索到结果 | `没有搜索到结果` |
| 确认弹窗 | 确定 X？或确定 X 吗？ | `确定删除消息？`、`确定退出服务台吗？` |
| 有后果的确认 | 后果在前，再问 | `关闭后，本次编辑的内容将不会保存，是否关闭？` |
| 后果说明 | X 后，你将无法 Y | `退出后，你将无法查看历史记录且不会再收到此群组的消息` |
| 开关说明 | 开启后，…… | `开启后，你将不再收到当前会话中的新消息提醒` |
| 没有权限 | 你没有 X 权限、暂无权限 | `你没有访问权限`、`暂无权限` |
| 找人处理 | ……，请联系 X | `没有权限，请联系企业管理员` |
| 上限 | X 已达上限，无法 Y | `群人数已达上限，无法添加新成员` |
| 数量限制 | 最多可 X N 个、至少选择一个 X | `最多可添加 1 个视频`、`至少选择一个群成员` |
| 输入 | 请输入 X、请选择 X | `请输入群名称`、`请选择` |
| 校验 | 请输入有效的 X、最多 N 字 | `请输入有效的电话号码`、`字数超出限制，最多 {num} 字` |
| 引导去别处 | 去 X、前往 X | `去查看`、`前往设置` |
| 重试入口 | 点击重试 | `点击重试` |

## 五、常用按钮

| 用途 | 按钮 |
|-|-|
| 确认 | `确定`、`完成`、`保存`、`好的`、`我知道了` |
| 取消 | `取消`、`关闭`、`拒绝`、`暂不`、`跳过`、`下次再说` |
| 操作 | `删除`、`复制`、`编辑`、`添加`、`移除`、`分享`、`下载`、`发送`、`转发`、`撤回`、`清空` |
| 查看 | `查看`、`查看详情`、`更多`、`展开`、`收起`、`搜索` |
| 流程 | `下一步`、`上一步`、`返回`、`退出`、`重试`、`刷新`、`重新加载`、`立即更新` |
| 引导 | `去查看`、`前往设置` |

## 六、时间

- 一分钟内写「刚刚」；一小时内写「N 分钟前」；当天写「N 小时前」；前一天写「昨天 HH:mm」。
- 星期写 `周一` 到 `周日`。
- 日期写 `M月d日`。

## 七、写完自检

- 称呼是不是都用「你」；感叹号和语气词是不是只出现在新功能介绍、引导和空状态里。
- 提示、说明和报错的句末有没有多出句号，问句有没有问号。
- 名称和菜单路径是不是写在“”里，产品自己的名字有没有多加引号。
- 数字、英文单词和变量两边有没有留空格。
- 权限和安全限制是不是先写原因、再写找谁处理。
- 同一个概念前后是不是同一个词。
