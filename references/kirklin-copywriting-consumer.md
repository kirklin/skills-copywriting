# C 端应用界面文案规范

## 一、范围

适用于个人社交、消费类和个人工具类产品，覆盖用户看得到的所有文字：按钮、标题、标签、提示、弹窗、报错、空状态、开关说明、引导、通知和菜单栏。示例里的 `{产品名}` 换成产品自己的名字。

## 二、硬性规则

1. 称呼统一用「你」，不用「您」。
2. 不用感叹号、表情符号、语气词（哦、啦、呢、吧、哈）和网络用语。
3. 只写结果和下一步，不写「为免」「因为」「这样就」「意味着」这类理由句。确实需要说明原因时，写成「由于 X，无法 Y。」：`由于磁盘空间不足，无法迁移。`；涉及账号安全时写「为了保障你的账号安全，……。」：`为了保障你的账号安全，本次操作需先在手机上完成安全验证。`
4. 不出现技术词，例如 OCR、布局、像素、坐标、线程、引擎、钩子、句柄、进程、接口、缓冲区，换成用户能懂的说法，例如 OCR 写成「文字识别」。
5. 完整的句子以「。」结尾，包括弹窗正文、说明文字和两句以上的提示。按钮、标签、标题和状态不用句号；几秒后自动消失的轻提示可以不用：`服务器繁忙，请稍后再试`。
6. 界面上的名称（按钮、页面、功能和其他应用）写在「」里：`在「访达」中显示`、`用「预览」打开`。产品自己的名字直接写，不加引号：`为了保证良好的网络连接，请不要关闭{产品名}`；产品里单独的工具照界面名称处理：`备份服务暂不可用，请重新启动「{产品名}备份工具」后再试。`。用户自己起的名字写在英文双引号里：`删除"%s"？`、`你已删除"%s"`。
7. 菜单路径写在「」里，层级之间用「 > 」，大于号两边各留一个空格：`你可以在「设置 > 通用」中启用或关闭此功能。`
8. 数字和变量紧贴汉字，不留空格：`最多可以添加3张图片`、`%d条新消息`、`%s提到了你`。英文单词和按键名两边留空格：`以下内容由 AI 生成，仅供参考`、`展开输入框，用 Enter 键换行`。
9. 括号和冒号用全角。
10. 进行中的状态写「正在 X」，末尾不加省略号。省略号写成三个英文句点，只用在点击后会弹出窗口或菜单的按钮上：`转发...`、`另存为...`、`下载到...`。
11. 按钮 2 到 4 个字，不用标点。
12. 不用「温馨提示」「请注意」「建议你」「抱歉」开头。

## 三、句式

| 场景 | 写法 | 示例 |
|-|-|-|
| 没做成 | 未能 X、X 失败 | `未能保存`、`发送失败` |
| 没做成，给出下一步 | 未能 X，请稍后再试 | `未能保存，请稍后再试`、`登录失败，请稍后再试` |
| 做不了，说明情况 | 无法 X；情况在前时写「X，无法 Y。」 | `无法发送超过%s的文件`、`表情过大，无法添加。` |
| 做不了，给出办法 | 无法 X，请 Y。 | `无法找到该用户，请检查你填写的账号是否正确。` |
| 暂时做不了 | 暂无法 X；需要用户先做某事时写「暂无法 X，需 Y。」 | `暂无法备份`、`暂无法备份，需允许{产品名}对这台电脑的相关设置进行更改。` |
| 不支持 | 暂不支持 X | `暂不支持发送文件夹` |
| 请用户稍后再操作 | ……，请稍后再试 | `操作过于频繁，请稍后再试。` |
| 正在进行 | 正在 X | `正在加载`、`正在备份` |
| 完成 | 已 X；耗时长的任务完成时写「X 已完成」 | `已保存`、`已复制`、`备份已完成`、`导出已完成` |
| 空状态 | 暂无 X、没有 X | `暂无聊天记录`、`没有更多的搜索结果` |
| 确认弹窗 | 动词开头直接问，以「？」结尾，不加「确定」「吗」 | `删除该收藏？`、`清空聊天记录？` |
| 后果说明 | X 后，……。 | `删除后，已备份的全部聊天记录将无法恢复。` |
| 开关说明 | 开启后，……。 | `开启后，所有聊天收到的消息会被自动翻译。` |
| 引导去别处 | 你可以在「A > B」中 X。你可以前往 X | `你可以前往文件夹自行删除` |
| 权限 | X 权限未开启 | `麦克风权限未开启` |
| 上限 | X 已达上限，无法 Y | `人数已达上限，无法邀请新成员` |
| 数量限制 | 最多只能选择 N 个 | `最多只能选择%d个文件` |
| 提醒用户不要做某事 | 情况，请不要 X。 | `该文件可能存在风险，请不要轻易打开他人发送的可执行文件。` |
| 网络 | 当前网络不可用，请检查网络设置 | `当前网络不可用，无法通话，请检查你的网络设置` |

## 五、常用按钮

| 用途 | 按钮 |
|-|-|
| 确认 | `确定`、`完成`、`保存`、`我知道了`、`允许` |
| 取消 | `取消`、`关闭`、`拒绝`、`暂不开启` |
| 操作 | `删除`、`收藏`、`转发`、`复制`、`编辑`、`移除`、`添加`、`清空`、`更改`、`重命名`、`下载`、`打开` |
| 查看 | `展开`、`收起`、`更多` |
| 流程 | `继续`、`返回`、`再试`、`退出` |
| 引导 | `去允许`、`去修改`、`前往设置` |

## 六、菜单栏

电脑端应用的菜单栏照系统的惯例写，应用名写产品名：

| 菜单 | 菜单项 |
|-|-|
| 应用 | `关于{产品名}`、`服务`、`隐藏{产品名}`、`隐藏其他`、`退出{产品名}` |
| 编辑 | `撤销`、`重做`、`剪切`、`拷贝`、`粘贴`、`全选` |
| 窗口 | `最小化`、`缩放`、`前置全部窗口` |

## 七、时间

- 一分钟内写 `刚刚`；一小时内写 `%d分钟前`；当天写 `%d小时前`；前一天写 `昨天`。
- 星期写 `周一` 到 `周日`。
- 日期写 `M月d日`，跨年时写 `yyyy年M月d日`。

## 八、写完自检

- 称呼是不是都用「你」，有没有感叹号、表情符号、语气词和技术词。
- 完整的句子有没有句号，按钮、标签和状态有没有多出标点。
- 界面名称是不是写在「」里，产品自己的名字有没有多加引号，用户起的名字是不是写在英文双引号里。
- 数字和变量是不是紧贴汉字，英文单词两边有没有留空格。
- 进行中的状态是不是「正在 X」，确认弹窗是不是动词开头直接问。
- 同一个概念前后是不是同一个词。
